# Правила проекта

- Используй Python 3.11+, FastAPI, Pydantic v2 и SQLAlchemy 2.x.
- Сверяй изменения с исходным заданием и публичным контрактом API.
- Храни, рассчитывай и возвращай деньги целым числом копеек. Не используй `float`.
- Отделяй бизнес-логику от HTTP-обработчиков. Сохраняй простую структуру без лишних слоёв.
- Соблюдай допустимые переходы статусов; обновляй статус атомарно.
- Обеспечивай идемпотентность ограничением базы и обработкой конфликта вставки.
- Любое изменение бизнес-логики сопровождай тестами наблюдаемого поведения; используй изолированные тестовые базы.
- Изменяй схему базы через Alembic; поддерживай запуск миграций с чистой базы.
- Добавляй зависимости в `pyproject.toml` и обновляй соответствующие файлы зафиксированных зависимостей.
- Проверяй `ruff check .`, `ruff format --check .`, `pytest` и миграции перед сдачей изменений.
- Пиши документацию и пользовательские инструкции на русском языке.
- Добавляй комментарии только для неочевидных причин и ограничений.
- Не сохраняй секреты, локальные базы, кэши и виртуальное окружение в Git.
- В `AI_LOG.md` описывай только фактически использованные запросы, ошибки и выполненные проверки.
