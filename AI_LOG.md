# Журнал работы с ИИ

Дата: 19 октября 2026 года. Использованы Claude (Claude Sonnet), встроенный терминал и параллельные ИИ-помощники для тестов, инфраструктуры и независимого review. Источники требований — переданные PDF на трёх страницах и подробная текстовая инструкция; API библиотек сверялся с официальной документацией.

## Реальные запросы

1. Исходный запрос пользователя, фрагмент: «самостоятельно реализовать полностью готовый к проверке проект в текущем рабочем репозитории». Контекст включал PDF, приоритет точной денежной арифметики, идемпотентность, конкуренцию и требования к документации.
2. Внутренний запрос помощнику по тестам, фрагмент: «реализуй pytest/httpx тесты на отдельной файловой SQLite с Alembic, строгую валидацию, деньги, идемпотентность, все переходы, HMAC, фильтры, конкурентные запросы».
3. Внутренний запрос на review, фрагмент: «проверь соответствие PDF, конкуренцию SQLite/PostgreSQL, строгость Pydantic, HMAC до JSON parse, транзакции и угрозы потери копеек».

## Найденные ошибки и проверка

Первая версия валидатора DATABASE_URL пропускала наружу `SQLAlchemy ArgumentError`. Независимый проверочный вызов обнаружил это; добавлен перевод в `ValueError`, чтобы Pydantic формировал штатную ошибку настроек, и регрессионные тесты.

Запросы с `1e400` или `NaN` обнаружили HTTP 500 при сериализации диагностического `input` ошибки валидации. Обработчик теперь сохраняет стандартную структуру `detail` и HTTP 422, представляя неограниченные числовые значения в диагностике строками. Денежные расчёты остались целочисленными. Исправление проверено тестами и настоящим HTTP-запросом.

Итог: **197 тестов пройдено, 0 падений**; все семь конкурентных сценариев синхронизируются через `Barrier`, без `sleep`. Обе проверки Ruff успешны. Проверены миграции с нуля и их откат, примеры curl, установка production-зависимостей в чистое окружение и сохранение платежа после полного рестарта Uvicorn. Суммы выше `2**53` в тестах обнаруживают скрытый `float`. Предупреждение Starlette о TestClient с HTTPX не подавлялось. Проверки выполнены на Python 3.12.14 и SQLite; для PostgreSQL сформирован SQL миграции без подключения. Docker и GitHub Actions в этой среде не запускались.
